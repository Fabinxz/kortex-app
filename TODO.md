## 📝 Feature Request Process

Have an idea not listed here?

1. Check if already suggested (GitHub issues)
2. Open a new issue with:
   - Clear description
   - Use case
   - Expected behavior
   - Nice-to-have: mockups
3. Tag with `feature-request`
4. Community votes with 👍
5. Prioritized by maintainers
